# Authority Dashboard (Person D)

One responsive web app, works on control-room screen + guard's phone.

**Views:** Registration (stub login, fee, tap-to-bind) · Live Map (zones color-coded, tourist pins, CCI risk, exit arrows) · Alerts (severity-ranked feed + E-FIR one-click).

**Modes:** crowd + trek (demo venue = "both"). Use Leaflet + OpenStreetMap for the map (no API key).
